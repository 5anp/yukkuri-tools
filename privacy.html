このアプリについて

YouTubeDrYukkuri は、YouTube チャンネル「ドクターゆっくり」の運営者が自分のチャンネルの分析データを読むための個人用ツールです。運営者本人のほかは使いません。

使う権限

  • https://www.googleapis.com/auth/youtube.readonly（チャンネルと動画の情報の読み取り）
  • https://www.googleapis.com/auth/yt-analytics.readonly（YouTube アナリティクスの読み取り）

どちらも読み取り専用です。動画の投稿、編集、削除、コメントの書き込みなどは行いません。

取得するデータと使い方

運営者自身のチャンネルについて、視聴回数、視聴時間、維持率、流入元、検索語、視聴者の属性（集計値）、インプレッションとクリック率、公開コメントを取得します。目的は、運営者が動画の改善を判断することだけです。

保存と共有

  • データは運営者の PC にだけ保存し、第三者に提供、販売、公開しません。
  • 他人が書いた公開データ（コメント、他の動画のタイトル）は、30 日を超えて古いまま保持しません。
  • 認可のトークンは運営者の PC にだけ保存します。

このアプリによる Google API から受け取った情報の利用と他アプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。また、YouTube 利用規約と Google プライバシー ポリシーに従います。

アクセス権の取り消し

Google アカウントのサードパーティのアクセスのページから、いつでも取り消せます。
